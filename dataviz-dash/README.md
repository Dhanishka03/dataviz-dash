# DataViz Dash

DataViz Dash is a lightweight data visualization dashboard that renders bar and line charts directly in the browser using plain JavaScript and Canvas. It's a quick way to explore and filter datasets without any server-side dependencies.

## Features

- Display bar and line charts rendered with HTML5 Canvas
- Filter chart data by category or time range to focus on what matters
- Import CSV files to load your own data into the dashboard
- Real-time WebSocket updates so the charts stay in sync with live data streams
- Backend API framework for managing and serving datasets
